## 通用功能

### 样式配置
- 点击**设置**按钮打开样式面板
- 修改后点击**保存**应用更改
- 点击**取消**放弃更改

### 数据编辑
- 点击图表上的**刻度标签**可直接编辑
- 点击**轴名称**可修改轴标题
- 点击**图例**可修改系列名称

### 导出图片
- 支持 PNG、JPG、SVG、TIF 格式
- TIF 格式使用 UTIF.js 编码
- 默认 300 DPI 打印质量

### 样式保存/恢复
- **保存**：将当前样式保存到浏览器本地存储
- **恢复**：从本地存储恢复之前保存的样式
